How to read this

Each line is one respiratory season, counted from September 1. The Public Health Agency of Canada publishes a weekly wastewater average for each virus. Its dashboard states no unit, so compare each virus only with its own history, never one virus with another. Some sites report a week or more late, and a single reading can spike, so the signal is stronger when the next weeks hold.

Comparisons use the same calendar week, within four days. A place needs about half a season of earlier readings to be included.
